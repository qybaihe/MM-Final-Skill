# B题“碳化硅外延层厚度的确定”求解与写作计划 v2

## 1. 总体定位

全文叙事主线为：**以色散光程相位为统一坐标，先在一次回程假设下用双角信息稳健反演厚度，再用分块置换与跨角谐波指纹检验模型是否必须升级，并只在证据触发处保真剥离多回程影响。**

这条主线刻意不按题号重复“假设—建模—求解—检验”八股结构，而把三问组织成一条可证伪的模型升级链：

1. 问题1规定基础机制：只保留表面反射与界面一次回程，建立含折射率色散和入射角的连续相位模型。
2. 问题2把模型落实为碳化硅实测算法：用动态规划峰链与双角共享厚度反演，并以连续盲块、经验覆盖率和透明异常对照评价可靠性。
3. 问题3不预设Airy成立：先把多光束必要条件转成数据验收指标，再用置换门控谐波指纹判定硅是否局部或持续触发；碳化硅只有在触发且修正确有盲块收益时才重算。

## 2. 数据事实与统一处理协议

四个附件均为单Sheet、两列、7469条记录，波数键逐值一致，范围399.6747—4000.122 cm⁻¹。波数严格递增，但步长仅近似均匀：中位数0.482 cm⁻¹、范围0.481—0.483 cm⁻¹。因此，峰位和物理相位算法直接使用原始波数坐标；FFT只允许在检查并等距重采样后作为基线。

附件1/2是同一块碳化硅晶圆的10°/15°测量，反射率相关系数0.99866977，但平均绝对差仍有1.39227678个百分点；附件3/4是同一块硅晶圆的10°/15°测量，相关系数0.99427894，平均绝对差3.38843856个百分点。两角必须分别输入、共享物理厚度，但不得直接平均反射率曲线。

质量处理冻结如下：

- 四附件399.6747 cm⁻¹首点均为0，首跳是后续局部典型差分的约369—803倍。默认标记并剔除，但必须保留“含首点/不含首点”敏感性对照，不覆盖原值。
- 附件2在801.278—927.1104 cm⁻¹有262点超过100%，占3.507832%，最大102.7393552%。禁止截断到100%；分别比较原值纳入、整段排除、仅用峰位三种口径。

## 3. 问题1：一次回程的双角色散相位模型

### 3.1 物理模型

在外延层表面反射光与外延层—衬底界面一次反射返回光之间建立两光束模型：

\[
R_\theta(\sigma)=B_\theta(\sigma)+A_\theta(\sigma)\cos\phi_\theta(\sigma)+\varepsilon_\theta(\sigma),
\]

\[
\phi_\theta(\sigma)=4\pi d\,\sigma\sqrt{n^2(\sigma,N)-\sin^2\theta_0}+\phi_r(\sigma).
\]

其中，\(\sigma\)为波数，\(d\)为外延层厚度，\(n(\sigma,N)\)显式表示波数和载流子参数对折射率的影响，\(B_\theta\)与\(A_\theta\)允许随角度和仪器响应缓慢变化。厚度由展开相位对色散光程坐标的斜率识别，而不是把折射率固定后对相邻峰距取均值。

### 3.2 主方法与定制改造

主方法采用锦标赛优胜的Q1-B。定制改造命名为**双角色散单调相位坐标（D2-MPC）**：

1. 用稳健低阶基线与局部振幅标准化获得振荡分量。
2. 分连续训练块计算Hilbert解析相位，裁剪边界影响区。
3. 以局部振幅作为相位可信度，进行加权单调投影，减少低振幅相位跳变。
4. 以\(\sigma\sqrt{n^2(\sigma,N)-\sin^2\theta_0}\)构造色散光程坐标。
5. 10°/15°共享厚度和材料色散，保留角度独立基线、振幅和相位截距，以soft-L1回归估计参数。

这一改造专门针对约10倍波数跨度、双角同源结构以及解析相位边界/低振幅失真的实际数据特征。

### 3.3 验证与算法对比

- 基线：常折射率相邻峰距公式。
- 败者对比A：Q1-A色散光程—整阶稳健回归，优点是离散阶次清楚，弱点是峰位定位和漏阶累积；原型MdAPE为2.632337%。
- 败者对比C：Q1-C双角全波形可分离非线性反演，优点是完整波形机制，弱点是基线、振幅与色散参数相关；原型MdAPE为5.176697%。
- 正式复验必须统一半合成真值锚点，因为Q1-A原型使用13.747913 μm，Q1-B/C使用14.0 μm；原型排序保留为路线筛选证据，但论文最终对比使用同一真值、同一噪声和同一缺损设定。
- 交叉印证相位斜率、峰谷整阶关系和全波形残差；若三者厚度量级冲突，优先排查色散先验与相位边界，而不是平均结果。

### 3.4 区间协议

若问题1验证报告厚度区间，采用连续波段移动块重采样的2.5%—97.5%**经验分位区间**。在不少于100组已知厚度、真实网格驱动的半合成光谱上，报告95%名义覆盖率、实际覆盖率和平均区间宽度；覆盖不足时扩大块长或明确降级结论，不得只给形式区间。

## 4. 问题2：碳化硅双角峰链反演

### 4.1 主方法

主方法采用Q2-A峰链动态规划—双角整阶回归，定制为**双角奇半阶峰链（DA-HOC）**：

1. 在原波数网格上以固定物理平滑尺度宽松生成峰、谷候选，`find_peaks`只负责候选，不直接决定结果。
2. 构造二阶动态规划。状态同时记录候选类型、局部间距和前一跳阶数；峰谷必须交替，正常相邻极值相差半阶，漏掉若干极值对应奇数个半阶跳跃。
3. 联合10°/15°峰链，用Huber损失拟合共享厚度与低维色散参数；再由共享模型反向检查候选链，删除不满足双角光程关系的弱极值。
4. 分别输出附件1的10°厚度、附件2的15°厚度，再给共享厚度；禁止只报一个合并值。
5. 对每个结果给经验分位区间、分波段稳定性、双角差和异常处理敏感性。

动态规划必须特别检查附件1约1543/1552 cm⁻¹、附件2约1628/1636 cm⁻¹附近间隔仅8—9 cm⁻¹的弱峰谷对，验证它们是否因不符合主条纹半阶尺度而被全局链拒绝。

### 4.2 防泄漏验证

在1200—2400 cm⁻¹等有效波段设置多组连续盲块，其中1680—1920 cm⁻¹固定为一组核心盲块。候选阈值、平滑尺度、漏阶惩罚和色散边界只由外侧训练块与校准块确定。验证指标为：

- 峰、谷分类后的双向最近位置MdAE，单位cm⁻¹；
- 预测与观测极值数量差；
- 盲块相位残差与分波段厚度偏差；
- 10°/15°独立厚度与共享厚度的区间相容性。

Q2-B原始MdAE虽为7.527738 cm⁻¹，但其单向最近匹配不惩罚额外预测，实际每角度仅1峰1谷观测却产生约10—11个同类预测，因此作为“指标设计会改变冠军”的失败案例写入论文。Q2-C保持极值数量一致但MdAE为14.81931332 cm⁻¹，且色散斜率贴近搜索边界，作为原网格物理匹配与可辨识性对照。

### 4.3 可靠性与区间覆盖

95%厚度区间采用连续波段移动块重采样的经验2.5%—97.5%分位构造。用至少100组半合成光谱检验经验覆盖率；这些光谱保留真实波数网格、基线、局部振幅、噪声尺度、首点异常和附件2归一化异常结构。可靠性结论至少包括：

- 10°、15°点估计与区间是否相容；
- 共享厚度是否降低跨角差而不恶化盲块误差；
- 含/不含共同首点的厚度偏移；
- 附件2异常波段纳入、排除、仅用峰位时的偏移；
- 平滑尺度、候选显著性、漏阶惩罚和色散参数±20%扰动；
- 入射角小幅仪器误差对厚度的传播。

## 5. 问题3：多光束必要条件与谐波验收

### 5.1 必要条件的可计算化

多光束不是“有多次反射的物理可能性”就自动成立，至少需要四类条件共同验收：

1. 后续回程幅度未被界面透射、吸收和散射衰减到噪声以下。
2. 光源相干长度与仪器分辨率足以保留、分辨对应往返光程差。
3. 界面在光斑尺度内近似平行，厚度起伏不致洗掉高阶回程。
4. 经色散和角度修正后，数据出现两光束基本余弦无法解释的稳定高阶结构，并在同一晶圆的10°/15°匹配光程位置复现。

附件3/4的最大反射率79.8019744%和91.48944351%只作为幅度背景，不能单独判定多光束。

### 5.2 主方法与触发规则

主方法采用Q3-B，定制为**跨角置换门控谐波指纹（CAP-HF）**：

1. 先用K=1基本波模型估计共享厚度和材料色散，建立相位坐标。
2. 在连续滑动窗口中拟合K=1与K=4谐波模型，计算2—4阶高阶能量比。
3. 在每个窗口内按连续训练块做分组置换，以置换统计量的95%**经验分位**构造局部触发边界。
4. 高阶能量必须在10°与15°均超过各自阈值，并在消除基本相移后达到至少0.5的指纹相似度，才局部启用K=4；否则保持K=1。
5. 结论分级：零窗口触发为“无多光束数据证据”；少数窗口触发为“局部多光束”；多数匹配窗口稳定触发才称“持续多光束”。原型中硅仅1/3窗口触发，因此正式求解必须扩展全谱滑窗复核，不能预写成全谱Airy成立。
6. 厚度由基本波保持；显著高阶项只用于诊断和必要时剥离，避免多回程振幅改变把厚度参数带偏。

### 5.3 硅厚度与碳化硅条件修正

附件3、4分别输出硅厚度及经验分位区间，同时给共享厚度和窗口级触发地图。以Q3-A嵌套Airy的有效往返幅比\(\rho\)及Q3-C稀疏回波的稳定\(q\ge2\)原子作交叉印证，而不是因其模型更复杂就自动采纳。

碳化硅条件任务依赖问题2的已验证基线厚度与区间：

- 若附件1/2均未在匹配窗口满足置换阈值与跨角指纹复现，则明确判定“不触发修正”，并逐项列出未满足条件。
- 若出现局部触发，先剥离显著的2—4阶谐波，再沿用问题2相同波段、折射率、角度和区间流程重算。
- 修正只有在连续盲块误差改善、10°/15°一致性不恶化、厚度变化超过或合理落入基线不确定区间时才有解释价值；否则将触发降级为“检测到局部非正弦结构，但不足以证明影响厚度精度”。

### 5.4 风险边界与覆盖检验

CAP-HF的95%触发边界明确采用**连续训练块分组置换统计量的95%经验分位**，不是理论正态阈值。在纯K=1半合成数据上报告经验误报率，在含K=2—4已知回程强度的数据上报告检出率。硅厚度区间同样采用移动块经验分位法，并在已知厚度的两光束/多回程混合半合成样本上报告名义95%与经验覆盖率。

灵敏度网格包括：窗口384/512/640点、块长48/64/80点、最高谐波K=3/4/5、置换分位90%/95%/99%、指纹阈值0.4/0.5/0.6，以及色散、角度、基线阶数和首点处理扰动。

## 9. 刻意偏离典型答卷的五点

1. **常折射率峰距或裸FFT → 双角色散相位坐标与奇半阶峰链 →** 正面响应题面折射率非常数性，同时控制非等距采样、漏峰和峰序错误。
2. **首点和超100%值静默删除/截断 → 原值只读、含/不含首点及保留/排除异常波段对照 →** 异常处理可追溯，证明厚度不是清洗规则制造的。
3. **10°与15°作为独立答案或直接平均曲线 → 分别输入、共享厚度、角度独立基线/振幅 →** 把同晶圆事实转化为物理交叉约束。
4. **先套Airy再凭条纹尖锐解释 → 95%分块置换、高阶能量与跨角指纹共同触发 →** 多光束结论可证伪，局部证据不会被夸成全谱机制。
5. **只报单个厚度和双角相对误差 → 经验分位区间、半合成覆盖率、盲块外推与败者路线审计 →** 可靠性有覆盖率、误报率和失败案例支撑。
