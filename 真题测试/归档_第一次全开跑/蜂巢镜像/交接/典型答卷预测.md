# 典型答卷预测：碳化硅外延层厚度的确定

本文档只预测最容易出现的同质化答卷，并给出可执行的偏离方向；不实施建模，不提供任何厚度结论。

## 1. 必然撞车的方法

1. **把折射率直接当常数，套相邻峰谷间距公式。** 平庸卷会从相长干涉条件出发，直接写成 \(d=\Delta m/[2\sqrt{n^2-\sin^2\theta}\,\Delta\tilde\nu]\) 一类公式，用相邻峰（\(\Delta m=1\)）或首尾峰（\(\Delta m=M\)）算厚度。它是教材中薄膜干涉的第一直觉，但会绕开题面专门指出的 \(n=n(\lambda,N)\) 色散与载流子依赖。
2. **平滑后调用 `find_peaks`，对所有峰间距取均值。** 常见流程是 Savitzky–Golay 滤波—设一个 prominence/distance—自动寻峰—剔除“看起来异常”的间距—均值代公式。阈值通常凭图选，峰序是否漏检、不同波段折射率是否变化、峰谷结果是否一致都不会验证。
3. **把FFT主频直接换算为厚度。** 因波数轴近似等距，平庸卷会对整段反射率去均值后做FFT，取最大频率作为条纹频率，再代入常折射率公式；它省去逐峰编号，但往往忽略实际步长在0.4810—0.4830 cm⁻¹间波动、宽频段色散及低频基线对主峰的污染。
4. **问题3直接搬用法布里–珀罗/Airy公式。** 论文会写菲涅耳反射系数、等比级数和 Airy 强度公式，再用“反射率较大、相干长度足够、界面平行”作为多光束干涉条件；但不把每个条件转化成附件3、4可计算的判据，最终靠条纹“更尖锐”作目测判断。
5. **可靠性只用双角度结果的相对误差。** 最常见检验是分别算10°、15°厚度，报告 \(|d_{10}-d_{15}|/\bar d\)，数值小便宣称可靠；不会拆分折射率、入射角、峰位、波段选择和多光束机制所带来的不确定度，也不会给置信区间。

## 2. 必然撞车的论文结构

1. **完全按题号平铺。** “问题一：外延层厚度模型”“问题二：碳化硅外延层厚度计算”“问题三：多光束干涉与硅外延层厚度”，标题几乎照抄题目，章节之间没有统一的“光程差—频谱特征—厚度反演—机制诊断”主线。
2. **每问重复八股三段。** 各问都机械设置“模型假设—模型建立—模型求解—模型检验”，问题1已经定义过的变量和干涉条件在问题2、3重复抄写，却不说明单光束模型如何升级为多光束模型。
3. **数据处理被埋在模型求解中。** 寻峰阈值、去基线、异常点处理、有效波段和折射率来源散落在正文或代码里，缺少一张可复现的输入—预处理—诊断—估计—验证流程表。
4. **问题3把三个逻辑任务混成一章。** “必要条件推导”“附件3/4是否满足条件”“附件1/2是否触发修正”不分层，常出现先默认多光束、再用同一假设解释数据的循环论证；条件性重算也容易只在结尾一句带过。

## 3. 必然撞车的图表

1. **四张裸反射率折线图。** 横轴波数、纵轴反射率，四附件各画一张全范围曲线；不标399.6747 cm⁻¹共同零值首点，不标附件2在801.278—927.1104 cm⁻¹的超100%区间，也不展示处理前后差异。
2. **一张密集峰值标记图。** 在全7469点曲线上用红点标出所有 `find_peaks` 结果，但不给 prominence、最小峰距、漏峰/伪峰检查或局部放大图；标记密到无法核查峰序。
3. **四个厚度的裸柱状图。** 用附件编号作横轴、单个厚度作柱高，既无误差棒，也不按“同一材料、同一晶圆、不同角度”成对组织，图形只是在重复结果表。
4. **四附件相关系数热力图。** 会突出附件1/2相关系数0.99866977、附件3/4相关系数0.99427894，却把“反射率形状相关”误当成“厚度反演可靠”，不展示经角度修正后的厚度一致性或局部偏差。
5. **拟合曲线与原曲线叠加图。** 只展示视觉上贴合，不画残差随波数结构、峰位偏差或分波段误差；多光束模型即使改善了振幅拟合，也不会检验厚度参数是否更稳定。

## 4. 必然撞车的摘要与话术

1. **逐问报菜名。** 摘要按“针对问题一，建立薄膜干涉模型；针对问题二，采用寻峰算法；针对问题三，引入多光束干涉模型”的顺序复述目录，方法有名称但没有判据、验证对象和可复现细节。
2. **用形容词替代证据。** 高频表述包括“结果较为准确”“两种角度结果基本一致”“模型具有较强鲁棒性和普适性”，但不附角度差、区间、扰动范围或失败情形。
3. **机械引入物理公式。** 常以“由光的干涉原理可知”“根据斯涅尔定律”“查阅相关资料可得折射率”开头，直接跳到公式，不交代折射率在399.6747—4000.122 cm⁻¹宽波数范围内如何取值。
4. **把预处理包装成创新。** 摘要会称“创造性地结合SG滤波、峰值检测和FFT”，却不说明三者是相互校验还是任取其一，也不报告参数变化是否改变厚度。
5. **多光束部分先下结论后补理由。** 典型句式是“由图可知硅片存在明显多光束干涉，因此采用Airy模型”，缺少从必要条件到数据指标再到模型选择的证据链。

## 5. 必然的薄弱环节

1. **假设没有生效位置。** 会列“外延层均匀、界面平行、光源相干、忽略吸收”等假设，却不指出它们分别影响相位、条纹对比度、峰宽还是厚度偏差，也不在后文检验或讨论违背后果。
2. **折射率处理与题面冲突。** 只给一个常数 \(n\)，没有来源、适用波段、掺杂条件和色散函数；甚至碳化硅与硅沿用同一折射率处理方式，导致模型形式正确但参数物理含义不完整。
3. **异常数据被静默删除或截断。** 四附件共同首点为0、附件2有262点超过100%，平庸卷会直接删除“异常值”或把反射率截到100%，不保留原值、不说明规则，也不做对厚度结果的敏感性比较。
4. **多光束判定不可证伪。** 必要条件停留在文字层，附件3、4只靠曲线观感判定；附件1、2是否触发“消除影响并重算”没有明确的是/否结论及逐项证据。
5. **检验、区间和代码相互脱节。** 灵敏度只写“改变参数结果变化不大”，不给扰动比例和厚度变化；置信区间不给构造方法；正文说峰位法，代码却可能用FFT主频或人工选峰，附件1—4的参数也可能被分别手调。

## 6. 我们必须偏离的清单（按性价比排序）

1. **静默清洗 → 建立两项透明的数据质量对照。** 默认排除四附件在399.6747 cm⁻¹处的共同零值首点（首跳为局部典型差分的约369—803倍），但同时保留“含/不含首点”结果；附件2的262个超100%点（占3.5078%，801.278—927.1104 cm⁻¹，最大102.7393552%）不截断，另做排除该波段或仅使用峰位信息的对照。动作成本最低，评分收益是让异常处理可追溯，并证明结论不是清洗规则制造的。
2. **把双角度当两份独立答案 → 把它变成同一厚度的交叉约束。** 四表均有7469个完全一致的波数键，先对碳化硅10°/15°、硅10°/15°分别反演，再比较经入射角修正后的厚度、峰序和分波段估计；不得直接平均两条反射率曲线。附件1/2虽高度相关（0.99866977），平均绝对差仍为1.3923个百分点；附件3/4相关0.99427894，平均绝对差为3.3884个百分点，因此必须区分“曲线相关”和“参数一致”。评分收益是直接命中题面同晶圆双角度可靠性要求。
3. **全频段常折射率 → 显式携带色散并做常数模型对照。** 数据覆盖399.6747—4000.122 cm⁻¹，跨度约10倍；下游应在公式、代码和结果表中使用 \(n(\tilde\nu)\) 或分波段有效折射率，并把常折射率仅作为基线，报告两者造成的厚度偏移。评分收益是正面回应题面唯一被特别提醒的材料性质，避免最常见的物理简化失分。
4. **凭“条纹尖锐”判多光束 → 建立“必要条件—数据指标—触发结论”验收表。** 对附件3、4逐项计算可观测代理量，如峰宽、峰谷对比度、谐波能量、连续条纹的间距稳定性及双角度参数一致性；其反射率最大值分别为79.8020%和91.4894%，只能作为振幅背景，不能单独充当判据。对附件1、2另列同一张表，明确条件性重算是否触发。评分收益是把问题3从主观图判变成可复核证据链。
5. **单一寻峰或单一FFT → 采用“局部峰位法 + 全局频域法”互证。** 原波数步长中位数0.482 cm⁻¹、范围0.481—0.483 cm⁻¹；峰位法直接使用原坐标，FFT法则先等距重采样并检查窗函数/去趋势，再比较两法的分波段厚度。评分收益是同时控制漏峰与频域偏差，且无需引入与题意无关的复杂算法。
6. **只报一个厚度 → 输出分波段稳定性和可复现不确定区间。** 利用每份7469点数据，对峰选择、有效波段、平滑强度、折射率参数和入射角进行扰动或重采样；报告区间构造方法、区间宽度及10°/15°区间重叠，而非只给“相对误差很小”。评分收益是把可靠性从话术升级为量化证据。
7. **先上Airy模型再解释 → 仅在诊断触发后实施多光束修正，并保留前后同口径比较。** 若附件1/2触发条件，修正前后必须使用相同波段、折射率函数、角度和不确定度流程，分别报告10°、15°变化及双角度一致性是否改善；若不触发，也要给逐项不满足的证据。评分收益是严格履行题目的条件性义务，防止“为复杂而复杂”。
