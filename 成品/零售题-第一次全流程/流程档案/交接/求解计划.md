# 零售销售额预测与数据分析：整条求解与写作计划

## 一、总体路线

四问按“稳健画像—驱动识别—预测建模—预测落地”递进，问题3作为30分核心，投入最多篇幅与验证资源。主预测目标定为按 Order Date 聚合的月度总销售额：任务提示的有效月份约47个月，按原始数据逐月复核后为48个有订单自然月；其中2022—2024年36个月用于训练，2025年12个月作为题目指定测试集。月度粒度能保留年度季节性并为每季度提供3个观测，同时避免日度序列大量噪声和年度序列仅4个点的问题。日度数据只用于异常排查和辅助展示，不作为最终预测目标。

分析采用两层数据视角：9800条订单商品明细用于问题1、2的因素解释；月度聚合序列用于问题3、4的总量预测。所有结论区分“关联/预测贡献”和“因果作用”，因为数据缺少数量、折扣、利润、成本及营销投入，不能直接做价格弹性、利润优化或因果归因。

## 二、统一数据治理与口径

1. 以 GBK 读取 数据/data.csv，随后转存 UTF-8 中间数据；禁止采纳自动探测器的 ISO-8859-1 误判。
2. Order Date、Ship Date 均按 DD/MM/YYYY（Python格式 %d/%m/%Y）显式解析。对42行、20个订单的2019年发货年份异常建立修正标记，主分析将年份修正为2026，使发货时差回到3—7天；物流相关结论同时以“修正”和“置缺”两种口径做敏感性核验。
3. Postal Code 始终作为字符串并左补零到5位；11个 Vermont 缺失邮编保留缺失指示，不把邮编当连续数值。
4. Customer ID 前缀统一大写；产品聚合优先使用 Product ID，并保留32个 Product ID 多名称、16个名称多 Product ID 的冲突标志。
5. Row ID 和常量 Country 不进入模型。Row ID 3406/3407 的疑似重复在主口径去除一条，同时保留“不去重”敏感性结果。
6. Sales 原值0.444—22638.48，均值230.769、中位数54.49，强右偏；总额始终按原值计算，分布推断与回归使用 log1p、秩检验或稳健损失，高值订单只标记不机械删除。
7. Order ID 有4921个而明细有9800行；任何明细层抽样、置换或验证均以 Order ID 成组，严禁同一订单商品行跨集合。时间预测严格按照2022—2024训练、2025测试。

## 三、问题1：订单—月份双尺度稳健画像

### 目标与产出

在明细层给出 Sales 的均值、中位数、标准差、极值、分位数、偏度及高值集中度；在业务层以 Order ID、Customer ID、Product ID 去重计算总销售额、总订单数、有效客户数和产品数。按年、季度、月份、区域、品类、客户细分和发货模式展示规模、份额与波动。

### 主方法与本题改造

主方法为稳健描述统计、多尺度时间聚合和集中度分析。本题改造命名为“订单—月份双口径稳健画像”：一套口径保留原始 Sales 以守住业务总量，另一套口径使用中位数、IQR、P90/P50、Top 10%销售额占比和 log1p 分布刻画典型订单，避免均值230.769被远高于中位数54.49的少数大额明细误导；订单指标按4921个 Order ID 去重，避免9800行商品明细被误报为订单数。

### 验证

以未经治理的直接 pandas 汇总为朴素基线。交叉核验包括：月度销售额之和等于全表总销售额；季度之和等于年度之和；各分类份额和为100%；修正发货日期、置缺发货日期两种口径不应改变非物流统计；去重与不去重结果仅在疑似重复对应金额处产生可解释差异。

## 四、问题2：五维销售驱动的双证据识别

### 分析框架

时间维度使用年份、季度、月份和季节项；地理维度使用 Region、State，City 只作频数满足阈值后的补充；产品维度使用 Category、Sub-Category；客户维度使用 Segment，并补充客户历史频次/金额分层；物流维度使用 Ship Mode 与修正后的履约天数。Country 为常量，不参与分析。

先对 log1p(Sales)做分布无关的组间检验：两组用 Mann—Whitney U，多组用 Kruskal—Wallis，并报告 epsilon-squared 或秩二列相关等效应量；多重比较采用 Benjamini—Hochberg 校正。再训练仅用于解释关联的树模型/正则化模型，按时间外推计算分组置换重要性和稳定性。

### 本题改造

改造命名为“订单簇置换的双证据因子筛”。第一证据是稳健显著性与效应量，第二证据是时间外验证中的预测重要性；只有方向一致且在订单簇 bootstrap 中稳定的因素才列为核心驱动。置换与重采样以4921个 Order ID 为簇，修复9800行并非独立样本的问题；对17个子品类、49个州等多水平比较做 FDR 校正，降低偶然显著；对强右偏 Sales 使用 log1p/秩方法，避免1145条高于IQR阈值500.6405的高值明细主导结论。

### 验证与结论边界

基线为单因素均值排序和普通 Pearson/ANOVA。交叉印证要求：稳健检验的效应量、分组置换重要性、跨年度方向稳定性三者至少两项一致；对客户和产品历史特征只使用预测时点之前的信息；对高基数变量使用频次编码或折外目标编码。最终输出“增长驱动—经营短板”矩阵，但表述为关联证据，不宣称因果。

## 五、问题3：短序列月度销售的季节锚定组合预测

### 预测目标与候选模型

将每月全部明细 Sales 求和得到月度总销售额。训练集为2022年1月至2024年12月的36个月，测试集为2025年1月至12月的12个月。候选模型控制在适合短序列的范围：

- 季节朴素法：预测值等于上年同月，是必须击败的硬基线；
- 阻尼趋势 Holt—Winters/ETS：直接表达水平、趋势和12月季节性；
- 低阶 SARIMA：候选阶数受限，避免36点训练序列上过拟合；
- 谐波季节项加岭回归：以趋势、月份 Fourier 项和少量滞后构成可解释动态回归；
- 树模型只作为辅助备选，不在36个训练月上承担主模型角色。

### 本题定制模型

改造命名为“季节锚定—偏差校正组合预测”。先对月销售额做 log1p 变换，在训练期内使用滚动起点、多步长回测产生真实样本外误差；再以非负且和为1的约束，根据滚动 MAE/WAPE 学习季节朴素、ETS与谐波岭回归/低阶 SARIMA的组合权重，并对复杂模型权重加入轻度惩罚。反变换时使用训练残差的 smearing 因子修正对数预测回到原尺度后的系统性低估。该改造直接针对“仅36个训练月但要识别12月季节性”的小样本矛盾：季节朴素提供稳定锚，低自由度模型提供趋势修正，组合降低单模型选错风险。

### 调参与验证

训练期内部采用扩展窗口滚动验证，不随机打乱。优先用至少24个月训练后预测后续1、3、6、12个月；若某早期窗口无法稳定估计季节模型，则从可估计的最早起点开始并记录有效折数。超参数以滚动 MAE 为主、WAPE为辅选择，禁止查看2025年标签调参。

锁定模型后一次性预测2025年，按题意报告 MSE、MAE、MAPE，并补充 RMSE、WAPE、sMAPE、季度误差和预测区间覆盖率。与季节朴素、去年同期均值/移动平均两类基线比较；使用残差时序图、ACF/Ljung—Box、误差按季度分解和训练期滚动排名交叉印证。只有在2025测试集整体和多数季度均不劣于季节朴素时，组合模型才作为最终模型；否则回退到更简单且稳定的季节锚定模型。

## 六、问题4：总量一致的2026层级预测与经营策略

### 预测生成

问题3模型通过2025测试后，用2022—2025全部48个月重新拟合，预测2026年12个月及季度总额，并给80%与95%区间。分维度结果不独立堆叠多个脆弱小模型，而采用“总量锚定的层级份额收缩”：分别估计 Region、Category/Sub-Category、Segment、Ship Mode 的月度份额，将近12个月份额、同月季节份额和长期份额按历史稳定性加权收缩，约束每个维度各层份额非负且和为1，再乘以总量预测。这样可保证所有分维度预测严格回加到月度总额，并缓解稀疏州/子品类序列的不稳定。

### 策略生成

把问题2的稳定效应、2026预测增量、历史波动和预测区间宽度合成“机会—把握度”矩阵。策略按产品布局、区域营销、客户分层、物流履约、库存管理五类输出，每条含触发条件、动作、观察指标和复盘频率。例如：高预测增量且高稳定性的品类优先保障库存；高潜力但区间宽的区域采用小预算试点；高销售但高波动子品类采用安全库存分档；物流模式只依据销售关联和修正后的履约稳定性给建议，不虚构运输成本。

### 验证

基线为“2025各维度份额原样外推到2026”。交叉核验包括：所有维度逐月加总等于总量预测；份额模型在2025做伪实时回测并与固定份额基线比较；策略优先级分别用总量预测下界和中位数重算，检查结论是否稳健；对42行发货日期异常采用修正/置缺双口径复核物流建议。

## 七、整体验证链与执行顺序

1. 数据治理完成后先保存清洗审计表，再计算问题1全部 JSON/CSV 结果，最后绘图。
2. 问题2的检验、效应量、重要性和稳定性先落盘，再画因素图；核心因素清单作为问题3特征审查和问题4策略依据。
3. 问题3先生成所有滚动回测与2025测试结果，锁定最终模型后再画预测和残差图。
4. 问题4先生成2026总量、区间、层级份额和策略优先级表，再绘制预测扇形图与策略矩阵。
5. 每次真实尝试、失败和调整追加到 交接/实验记录.json；所有脚本在末尾打印结果摘要。

## 九、图表规划

全文规划14张图，折线类3张、柱状图0张，合计不超过总数一半；同一图型不超过3张。含3张自设计示意图，分别解释数据治理、五维机理和滚动验证。

1. 数据治理与口径分流图（自设计流程图）：唯一展示原始明细如何经过编码、日期、异常和去重治理后分流到明细分析与月度预测。
2. 月度销售趋势与季节分解图（多面板折线）：唯一同时呈现长期趋势、12月季节结构和剩余波动。
3. Sales 原尺度ECDF—对数密度联合图：唯一直接量化均值与中位数背离及高值长尾。
4. 各维度销售份额—波动气泡图：唯一在同一坐标中比较规模、稳定性和样本量。
5. 五维因素作用路径图（自设计机理图）：唯一说明时间、地理、产品、客户、物流如何进入统计检验、预测和策略链。
6. 因素效应量与显著性热图：唯一同时给出五维因素的影响强度、方向与FDR显著性。
7. 子品类—区域增长贡献象限图：唯一识别高贡献高增长、规模大但放缓等组合。
8. 客户细分与发货模式 Sales 小提琴图：唯一比较完整分布而非只比较均值。

12. 2025实际—预测及区间图（折线/带状区间）：唯一展示最终模型在题目指定测试年的逐月命中情况。
