# 蜂巢工作协议（本地工作根内所有智能体共同遵守）

你在数模论文流水线的本地蜂巢内工作，**当前目录就是工作根**。你是接力中的一环：上游交接文件是权威输入，你的产出是下游的依赖。

## 目录约定
- `题目/` 赛题 · `数据/` 原始数据 · `交接/` 交接文件（JSON/MD）· `求解/问题X/` 每问脚本与产物
- `求解/问题X/图片/` 图 · `求解/问题X/结果/` 数值结果 JSON/CSV · `论文/` tex 全套 · `审稿/` 审稿产出 · `日志/` 运行日志
- `运行时/模板参考/` Mrite 章节模板（参考其规范，不逐字照抄结构）· `运行时/HMML.md` 建模方法库

## 硬性环境规则
- 无外网（你的工具调用运行在 seatbelt 沙箱里，文件写权限锁在工作根内；不要尝试访问工作根以外的路径）。
- `python3` 直接可用且已装齐 numpy/pandas/matplotlib/scipy/sklearn/statsmodels/sympy/networkx/pypdf/openpyxl/python-docx/lxml——
  **不要**再往脚本里写 `sys.path.insert` 之类路径补丁，也不要 pip install（无外网，装了也没用）。禁 seaborn。
- `xelatex`、`gs`、`bash` 可用。数据 `数据/data.csv` 为 GBK 编码、日期 %d/%m/%Y（详见 交接/数据档案.json，其结论权威）。

## 代码与绘图规范
- 先算后画：先完成全部计算并把关键统计量与结果写入 `求解/问题X/结果/*.json`，再绘图。
- 中文字体：`plt.rcParams['font.sans-serif']=['FandolHei','Noto Sans CJK SC','DejaVu Sans']`；`axes.unicode_minus=False`
- LaTeX 字体：`论文/format.cls` 已全部按**文件名**加载（texgyre*.otf / Fandol*.otf）。本机 xelatex 按家族名查字体会找不到甚至挂死（病根 R39），改版式时不许写 `\setmainfont{家族名}`、`\setmonofont{DejaVu Sans Mono}` 这类按名加载，也不许把现有文件名加载改回去。
- 图不加 set_title（标题由论文 caption 承担）；`grid(alpha=0.3, linestyle='--')`；去顶/右边框；线宽≥1.5；dpi=200；`bbox_inches='tight'`；图例中文。
- 每个求解脚本跑完打印结果摘要（供日志追溯）。

## 交接纪律
- 交接 JSON 必须合法（无注释、无尾逗号），键名中文。
- **实验记录**：求解过程中每一次真实的尝试/失败/调整，必须追加到 `交接/实验记录.json`（数组，元素含：类别、问题、尝试、现象、决定、依据）。`类别` 词表固定：建模/解读腿用 `科学尝试|流程事件`；绘图、图评、撰稿、审稿/编译修复腿分别用 `绘图尝试|图评尝试|撰写尝试|工程修复`（门检把后四类视同流程事件，不进论文过程感素材）。`问题` 填整数题号，非某一问的填 0。这是论文"过程感"叙述的唯一素材来源，禁止杜撰。
- 完成任务后，把一段 ≤5 行的完成摘要写入你的任务指定的完成标记文件。
