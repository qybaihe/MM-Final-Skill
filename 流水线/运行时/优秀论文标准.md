# 优秀数模论文标准（评委视角，源自国赛官方规范与阅卷要点）

## 评委怎么读你的论文
- 初评单篇 **5-10 分钟**：先摘要，再翻图表，再看结论。摘要是成功参赛奖与省奖的分水岭。
- 因此：摘要四要素缺一不可（具体问题｜模型+算法点名｜**每问关键数值结果+单位**｜结论与灵敏度稳健性）；**每张图必须自明**——评委只看图+图题就能带走一个结论。

## 官方四要素
1. 假设合理性：每条假设必须能在正文找到"生效位置"（它简化了哪一步建模）；禁止"数据真实可靠"式万能假设。
2. 建模创造性：决策变量/约束与题目条件一一对应；标准方法必须有本题定制改造。
3. 结果正确性：数值可核验、带单位、量级合理；灵敏度分析必须有数值支撑，禁止只声称"模型稳定"。
4. 表述清晰：评委能沿"摘要→图表→结论"复述全文。

## 版式硬规范（国赛）
- 摘要独立一页；正文**尽量 ≤20 页**；**不放目录**；附录页数不限。
- **附录必须含全部关键可运行源代码**（缺代码/跑不通/与正文不符 → 可能取消评奖资格）。
- 图表必须被正文显式引用、有编号标题；图题在下、表题在上；符号首次出现即定义、全文无冲突。

## 语言与表述规范（决定"像不像一篇高水准论文"）

实测教训（20260827 轮）：那一稿数学推导规范、溯源完整，读起来却像**内部验证报告**而不是论文。
病灶不在措辞华丽与否，而在下面四条。

### 1. 论文写给评委，不写给流水线自己
正文**不得出现任何实现细节与内部质控术语**：代码、脚本、文件名（`.json`/`.py`）、
返回码、"置为真/写为 false"、"获准发布""正确性放行""预注册收敛协议""FAIL"。
评委不知道这些是什么，看到只会认为作者在描述自己的程序。

- ✗ 「代码已将"是否通过"写为 false 并立即停止，主方法与参数灵敏度均未生成。」
- ✓ 「网格加密后厚度估计的相对变化为 0.13%，略高于本文预设的 0.10% 收敛标准，
  故对该结果附加收敛性说明，并以加密网格的估计值为准。」

写的是**科学发现与判断**，不是**程序做了什么**。

### 2. 有效数字按测量精度收敛（正文小数位 ≤4，G4 会检）
JSON 里的浮点不能原样贴进正文。7469 个观测点的光谱反演，给到小数点后 6 位没有物理意义。

- ✗ `16.750590%`、`7.658250--8.062678 μm`、`0.9986697662`
- ✓ `16.8%`、`7.66–8.06 μm`、`0.999`

区间端点、百分比一般 2–3 位有效数字；只有当误差本身在该量级时才写更多位。

### 3. 每章先说"要解决什么、怎么想的"，再上数字
不要开篇就抛误差和阈值。评委需要先接住动机与思路，才看得懂后面的数值。

- ✗ 开篇即「一次往返光路的代数闭合误差只有 1.11×10⁻¹⁶，两项误差均未越过 10⁻¹² 核验阈值。」
- ✓ 先交代「本章把多次往返截断为一次往返，目的是得到一个可解析、可退化的零模型，
  作为问题三引入多光束修正时的对照基准」，再用误差数据支撑这个设计成立。

### 4. 结论章交答案，不交失败说明书
结论章的第一句必须是**题目问的那个量的数值**（带单位、带不确定性），
而不是"获准发布 0 项"式的过程裁决。指标未达预期时，写法是
「估计值 X ± Y（在 Z 条件下），其中某项检验略低于预期标准，故置信度按…下调」，
而不是拒绝作答。参见建模师/解读师的「必须作答」条款。

### 5. 先用朴素语言回答题目，再上术语（G4 检密度，不检有无）

这是 20260831 轮**四位审稿员连续四轮点名、改了四轮仍未解决**的问题。原话：

> 轮1A「正文反复出现『历史诊断、版本隔离、未放行、发布资格、当前入口』等内部审计话语，
> 尤其第 5、7、8 章像版本说明书」
> 轮2B「『证据门、共享锚、级联、放行边界』等术语密度仍偏高，部分段落像内部模型审计报告」
> 轮3B「术语密集，**却没有先用一句朴素语言回答题目**」
> 轮4A「『可交付答案、正检出、候选锚、模态走廊、证据门、升格』等内部裁决词仍密集，
> 摘要和结论更像质量审计报告」

**这不是要你不用术语。** 方法名该用就用——G4 检的是每千汉字的出现次数，
不是有没有出现（首读章即摘要/结论/引言 ≤10，其他正文章 ≤15，见 `运行时/内部术语.txt`）。
实测那一稿：摘要 17.9、结论 15.5 超线，而另有七章为 0，说明完全写得下来。

写法就照评委给的改：

- ✗「问题三 Airy 形态正检出但机制未独立确认，厚度不可交付。」
  ✓「硅片光谱确实出现了多光束干涉的形态特征，但支持这一机制的独立证据不足，
  因此本文不据此给出硅片厚度。」——**先回答"测得多少、能否相信、是否需要修正"，再括注术语**
- ✗「可交付答案」「升格」 → ✓「本文报告」「仅作诊断」
- ✗「不触发修正分支」 → ✓「证据不足，故本轮不执行修正；这不等价于证明不存在多光束」
- ✗ 摘要连用「对于问题一/二/三」 → ✓ 以问题特征开头：
  「在一次往返边界下…」「对碳化硅双角谱…」「面对硅片的高阶往返…」
- ✗ 强结论词超出证据许可（「多解范围」暗示已穷举）
  → ✓ 按证据等级命名（「双角条件点估计范围」）

**术语首次出现时补一句白话定义**，后文再用简称。评委不认识流水线自己造的词。

### 6. 表达四律：数字退后、置信一处、名字用人话、图题是陈述（G4 检，阈值只认真稿分布）

第 5 条治的是"用了什么词"，这一条治的是"读起来什么节律"。20260907 骨架版量出来的形态
（量尺 `运行时/表达画像.py`，阈值 `运行时/表达阈值.json`）：全文每千汉字 41 个数字、
摘要每千汉字 23 处保留话、96 处自造缩写、20 条图题带"另行检验/只保证"。评委的感受是
"像审计报告"，根子是四个可量的东西：

- **数字退后**：先说清对象与结论，数字跟在后面钉住它。段首不以数字开头；一段进句的数字
  两三个足矣，多了进表。✗「0.103\% 升至 0.383\%，约放大 3.70 倍；0.18、0.32 和 0.55 时又分别为…」
  ✓「多光束不是越多越糟：往返次数刚增加时偏差最大（中位数约 0.4\%），再增加反而回落到 0.15\% 附近。」
- **置信一处**：每问的保留话只在结论句后说一次，措辞照结果声明的置信字段。摘要、图题、标题、
  结论章一律陈述句。反复道歉不会让评委更信任你，只会让他记不住答案。
- **名字用人话**：不自造缩写（白名单外的大写串展开成中文），定制方法用 ≤12 字中文短语，
  流水线内部术语不进正文。术语第一次出现给一句白话定义。
- **图题是陈述**：对象 + 看到什么，≤25 字。✗「三问关键风险、证据层级与置信表述」
  ✓「两入射角下厚度估计随波数的收敛」。

这四条都有范文参照：`运行时/范文卡片库.md`（范式卡片）与 `运行时/表达锚点.md`（6/8/9 档锚点）。
评审腿打语言分时按它们说"更像范文还是更远"，不凭印象。

## 常见扣分清单（逐条自查）
- 摘要无具体数字 / 超一页
- 万能假设、假设与正文脱节
- 贴图不引用、图内文字不可读、图表信息密度低
- 灵敏度无数值 / 检验只做样子
- 参考文献与正文 \cite 不对应
- 问题重述整段抄题
- 叙述机械（"得到如下表"三段套）、结构八股
