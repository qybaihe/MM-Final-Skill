# 优秀数模论文标准（评委视角，源自国赛官方规范与阅卷要点）

## 评委怎么读你的论文
- 初评单篇 **5-10 分钟**：先摘要，再翻图表，再看结论。摘要是成功参赛奖与省奖的分水岭。
- 因此：摘要四要素缺一不可（具体问题｜模型+算法点名｜**每问关键数值结果+单位**｜结论与灵敏度稳健性）；**每张图必须自明**——评委只看图+图题就能带走一个结论。

## 官方四要素
1. 假设合理性：每条假设必须能在正文找到"生效位置"（它简化了哪一步建模）；禁止"数据真实可靠"式万能假设。
2. 建模创造性：决策变量/约束与题目条件一一对应；标准方法必须有本题定制改造。
3. 结果正确性：数值可核验、带单位、量级合理；灵敏度分析必须有数值支撑，禁止只声称"模型稳定"。
4. 表述清晰：评委能沿"摘要→图表→结论"复述全文。

## 版式硬规范（国赛）
- 摘要独立一页；正文**尽量 ≤20 页**；**不放目录**；附录页数不限。
- **附录必须含全部关键可运行源代码**（缺代码/跑不通/与正文不符 → 可能取消评奖资格）。
- 图表必须被正文显式引用、有编号标题；图题在下、表题在上；符号首次出现即定义、全文无冲突。

## 语言与表述规范（决定"像不像一篇高水准论文"）

实测教训（20260827 轮）：那一稿数学推导规范、溯源完整，读起来却像**内部验证报告**而不是论文。
病灶不在措辞华丽与否，而在下面四条。

### 1. 论文写给评委，不写给流水线自己
正文**不得出现任何实现细节与内部质控术语**：代码、脚本、文件名（`.json`/`.py`）、
返回码、"置为真/写为 false"、"获准发布""正确性放行""预注册收敛协议""FAIL"。
评委不知道这些是什么，看到只会认为作者在描述自己的程序。

- ✗ 「代码已将"是否通过"写为 false 并立即停止，主方法与参数灵敏度均未生成。」
- ✓ 「网格加密后厚度估计的相对变化为 0.13%，略高于本文预设的 0.10% 收敛标准，
  故对该结果附加收敛性说明，并以加密网格的估计值为准。」

写的是**科学发现与判断**，不是**程序做了什么**。

### 2. 有效数字按测量精度收敛（正文小数位 ≤4，G4 会检）
JSON 里的浮点不能原样贴进正文。7469 个观测点的光谱反演，给到小数点后 6 位没有物理意义。

- ✗ `16.750590%`、`7.658250--8.062678 μm`、`0.9986697662`
- ✓ `16.8%`、`7.66–8.06 μm`、`0.999`

区间端点、百分比一般 2–3 位有效数字；只有当误差本身在该量级时才写更多位。

### 3. 每章先说"要解决什么、怎么想的"，再上数字
不要开篇就抛误差和阈值。评委需要先接住动机与思路，才看得懂后面的数值。

- ✗ 开篇即「一次往返光路的代数闭合误差只有 1.11×10⁻¹⁶，两项误差均未越过 10⁻¹² 核验阈值。」
- ✓ 先交代「本章把多次往返截断为一次往返，目的是得到一个可解析、可退化的零模型，
  作为问题三引入多光束修正时的对照基准」，再用误差数据支撑这个设计成立。

### 4. 结论章交答案，不交失败说明书
结论章的第一句必须是**题目问的那个量的数值**（带单位、带不确定性），
而不是"获准发布 0 项"式的过程裁决。指标未达预期时，写法是
「估计值 X ± Y（在 Z 条件下），其中某项检验略低于预期标准，故置信度按…下调」，
而不是拒绝作答。参见建模师/解读师的「必须作答」条款。

## 常见扣分清单（逐条自查）
- 摘要无具体数字 / 超一页
- 万能假设、假设与正文脱节
- 贴图不引用、图内文字不可读、图表信息密度低
- 灵敏度无数值 / 检验只做样子
- 参考文献与正文 \cite 不对应
- 问题重述整段抄题
- 叙述机械（"得到如下表"三段套）、结构八股
