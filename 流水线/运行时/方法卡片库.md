# 方法卡片库（现代方法强化，补 HMML 之外的 2024-2026 主流实践）

定位：HMML 当**覆盖面清单**用（防漏想），本库当**选型与实现指南**用。每卡含适用信号/失败信号/离线实现要点/检验义务。规划师选型时两者都查；有冲突以本库为准。

## 卡1 · 分位回归 + 共形预测区间（预测区间的现代标准）
- 适用信号：任何需要报告预测区间/风险边界的任务。**区间协议（硬性）**：论文中任何区间必须写明构造方法，并给出留出集/滚动回测的经验覆盖率；覆盖不足必须披露。
- 失败信号：样本 <30 时共形区间过宽，改报经验分位数并注明局限。
- 实现要点（离线可用）：split-conformal——在校准集上取残差绝对值的 (1−α)(1+1/n) 分位数做半宽；分位数版用 GradientBoostingRegressor(loss="quantile", alpha=…) 或 statsmodels QuantReg 出上下分位，再共形校准（CQR）。多步时序用滚动起点逐步校准。
- 检验义务：报告名义覆盖 vs 经验覆盖；区间宽度随步长的变化。
- 文献：vovk2005conformal / romano2019cqr

## 卡2 · 层级预测一致性调和 MinT/OLS 调和（份额收缩的更优替代）
- 适用信号：需要"总量 + 分维度"同时预测且要求加总一致（区域×产品×客群）。
- 失败信号：层级很少（<5 叶）时直接自上而下份额分配即可。
- 实现要点：底层+汇总层分别预测 → 用调和矩阵 S 与误差协方差（可用对角近似=WLS）解 min‖ỹ−Sβ‖：numpy 最小二乘即可实现；对角权取各层残差方差。
- 检验义务：调和前后各层精度对比表（调和不应显著损害底层精度）；加总恒等式数值验证。
- 文献：wickramasuriya2019mint / hyndman2021fpp

## 卡3 · 直方图梯度提升 HistGradientBoosting（表格数据主力，替代裸 RF）
- 适用信号：中等规模表格回归/分类；需要非线性+交互；sklearn ≥1.0 自带（无需 xgboost）。
- 失败信号：样本 <500 或强外推场景（树模型不外推——时序外推期改用带趋势项的线性/ETS 锚）。
- 实现要点：HistGradientBoostingRegressor(loss="quantile") 可直接出分位数；early_stopping=True；类别列用 categorical_features。
- 检验义务：与线性基线与朴素基线同口径对比；分组时间外验证（防泄漏）。
- 文献：friedman2001gbm / pedregosa2011sklearn

## 卡4 · 分组感知交叉验证与置换重要性（因素归因的可信做法）
- 适用信号：明细数据有天然分组（订单/客户/日期）；要下"哪些因素重要"的结论。
- 失败信号：随机按行切分（同组跨训练测试=泄漏，结论作废）。
- 实现要点：GroupKFold / 时间外验证；重要性用置换重要性（在验证集上按组置换）而非树内 impurity；多重比较 BH 校正。
- 检验义务：跨年/跨切分方向一致性；阈值敏感性（结论翻转即降级表述）。
- 文献：breiman2001rf / benjamini1995fdr

## 卡5 · 稳健 STL 与结构变化检查
- 适用信号：月度/周度序列做趋势-季节分解叙事。
- 实现要点：statsmodels STL(robust=True)；变点粗查用滚动均值差的 CUSUM 或分段线性拟合残差比较（numpy 动态规划可实现 PELT 思路的简化版）。
- 检验义务：分解残差的 Ljung-Box；变点结论给出前后段统计量对比。
- 文献：cleveland1990stl

## 卡6 · 熵权-TOPSIS/AHP 的现代注意
- 适用信号：评价排序类问题。
- 失败信号：指标间高相关时熵权重复计权——先做相关性去冗或分组赋权；AHP 判断矩阵必须过一致性检验 CR<0.1 且给出矩阵来源理由。
- 检验义务：权重扰动 ±20% 的排序稳定性；两种赋权法交叉印证。
- 文献：shannon1948entropy / hwang1981topsis / saaty1980ahp

## 卡7 · 优化类问题离线求解要点
- 适用信号：线性/整数规划、指派、网络流。
- 实现要点（无商用求解器）：scipy.optimize.linprog(highs) 支持大规模 LP；milp（scipy≥1.9 自带 HiGHS MILP）；指派 scipy.optimize.linear_sum_assignment；网络流 networkx；启发式（GA/SA）必须与精确解或松弛界对比给 gap。
- 检验义务：可行性数值验证（约束逐条代回）；启发式多随机种子稳定性。

## 卡8 · 何时不用深度学习（评委视角）
- 国赛数据规模（千~万行）上，深度模型几乎必然过拟合且不可解释，评委不加分反扣说理分。表格/短序列一律优先统计模型+树模型；若坚持用，必须给出与简单基线的显著优势和过拟合防护证据。
