# 典型答卷预测：碳化硅外延层厚度的确定

依据：`交接/题面契约.json`与`交接/数据档案.json`。本文是动手前的风险预测，不是对已有答卷的评价；未检索外部题解，未拟合光谱、估算厚度或预判多光束干涉。下文“必然撞车”指应提前设防的模板化倾向。

**偏离原则：保留正确的基础方法和问题对应关系，偏离无依据的套用、无证据的结论与无法复核的写法。** 两束干涉公式、峰位法、FFT、Airy模型等并非禁用清单；不能为求不同而丢掉问题1的规定情形，或把问题2直接改写成与问题1无关的复杂模型。文中观测数字均来自数据档案，标“约”的值仅作舍入；所有建议的比较、图表和结果文件均待下游实际执行，不代表已经得到结果。

## 1. 必然撞车的方法

1. **常折射率＋相邻峰距公式直接代入。** 第一反应是套用同类相邻极值的常折射率近似式 `d=1/(2n cosθ_t Δσ)`，从印象里取一个折射率，把全谱平均峰距代入。可检验的撞车特征：未标明这是常折射率近似，未区分入射角与层内折射角，或将峰—谷间距当作峰—峰间距而不改系数；正文也没有说明折射率来源与适用波段。公式在此仅用于点名模板，不作为本题已建立的模型。
2. **Savitzky–Golay平滑＋`find_peaks`一套参数跑四谱。** 因为工具现成，平庸卷会全谱使用同一窗口、阶数、峰间距和显著度阈值，再平均全部相邻峰距。验收时看：是否只报“去噪后峰值”，不报参数、保留峰表、被排除峰及理由；是否把四分位围栏外点或大跳变点一律删掉，未核验峰位是否被平滑改变。
3. **全谱FFT取最高峰，再称为“主频厚度法”。** 第一反应是将7469行直接视为严格等距序列，一次去均值后FFT，取最大幅值频点对应厚度。可检验特征：没有波数步长口径、分析波段、基线/窗函数与频率轴单位，未区分基频与谐波，也未核验近似等距处理的影响；补零后频谱更细就被写成“测量精度提高”。
4. **四次独立估计＋算术平均＋相关系数背书。** 附件数很容易被误当作样本数：分别求四个厚度，把同材料两值直接平均，再用两角度原谱相关系数接近1证明准确。检查是否把同片不同角度当作独立重复测量，是否解释共同厚度与角度相关光谱差异，是否将内部一致性冒充对真实厚度的误差验证。
5. **多光束部分套Airy表达式或传输矩阵，非线性最小二乘后比拟合优度。** 因为“多次反射”很容易触发现成薄膜公式，平庸卷会预设硅必有多光束干涉，直接增加参数；只要训练集残差下降或拟合优度提高，就宣称判定成立、厚度精度提高。可检验特征：没有必要条件与实测证据的逐项对应，没有同波段同预处理的公平对照，也没有区分谱形变化、厚度变化与真实误差变化。

## 2. 必然撞车的论文结构

1. **总目录固定为“问题重述→问题分析→模型假设→符号说明→模型建立与求解→灵敏度分析→优缺点”。** 碰撞点不是这些内容不能出现，而是目录看不见“同片双角”“光谱异常”“多光束条件分支”等本题决策。可检查主结果是否被挤到大量背景和符号之后，评委能否直接找到每问的交付物。
2. **每问照抄题干标题，再重复“模型建立／模型求解／模型检验”。** 例如“问题二：根据问题一建立算法并求解附件1、2”。替代标题必须仍可评分：可用“相位差与厚度的对应关系（问题1）”“同片双角的厚度估计与可靠性（问题2）”“多光束证据与厚度修正分支（问题3）”。不能把章节改成只剩“追光”“寻厚”等无法定位问题的标题。
3. **按附件1→2→3→4机械拆成四个平行算例。** 可检验特征：重复四次相同推导，却没有附件1、2同属碳化硅、附件3、4同属硅的共同对象说明；问题3的碳化硅处理与问题2初始结果不在同一口径下对照。避免重复不等于允许省略任何附件的使用证据。
4. **结尾统一补一章“模型检验”，将全部论证移到附录。** 正文只有“误差较小、模型可靠”，关键波段选择、参数来源和条件分支藏在代码里；问题3的必要条件推导又与硅数据判定脱节。检查每个结论附近是否有直接支撑它的表、图或推导，以及能否从问题2结果追到问题3的触发/不触发处理。

## 3. 必然撞车的图表

1. **四条全谱裸折线挤在同一张图。** 横轴波数、纵轴反射率，仅用颜色区分附件；不区分材料和角度，不标共同首点与超100%区段，不标实际使用/弃用波段。附件2超过100%的部分甚至会被纵轴0—100的范围裁掉；大尺度背景下局部条纹是否可用无从检验。
2. **平滑曲线＋红色峰点图。** 全谱只画处理后的曲线和“保留峰”，不叠原始局部曲线，不标峰序、候选峰/拒绝峰及拒绝理由，不提供峰位表。缺的是“这个峰为什么能参加厚度估计”的证据，而不是点的颜色不够丰富。
3. **FFT振幅谱画一根最大峰箭头。** 不写变换前选段及预处理，横轴直接写“频率”或未经说明就写“厚度”；没有候选峰和谐波位置、窗口变化对照，也不说明补零不等于增加原始信息。图看似给出精确主峰，却无法追溯到原始波数坐标。
4. **四附件相关系数热力图。** 格子四舍五入到两位小数，高相关都变成接近1的颜色，再配“数据一致、模型可靠”。缺的是同片两角度的实际差值曲线、局部偏差和厚度层面的检验；跨材料高相关更不能说明是一块晶圆，也不是多光束干涉证据。
5. **四个厚度裸柱状图，或原谱/拟合曲线完全重叠图。** 柱子按附件编号排而不按两块晶圆分组，没有单位、区间、使用波段与条件说明；拟合图没有共享波数轴的残差面板。若给“修正前/后”柱子却不说明是否触发修正、输入是否相同、区间是否可比，图不能支持精度改善。

## 4. 必然撞车的摘要与话术

1. **按题号流水账。** “本文针对问题一建立了两光束干涉模型；针对问题二采用峰值检测算法；针对问题三建立多光束干涉模型。”可检验特征：摘要主要篇幅报方法名，却没有分别覆盖两种材料的结果对象、两个角度的数据使用、可靠性边界和碳化硅条件分支；不能用“有模型”替代“答了什么”。
2. **无依据地写“误差很小、精度很高”。** 典型句式是“两个角度结果接近，证明测量准确可靠”。缺少真实厚度或标准样品时，结果接近只能作为待解释的一致性证据，不能报对真值的相对误差；检查每个“误差”是否有明确参照量，每个区间是否有构造方法。
3. **把清洗写成无代价的成功叙事。** “剔除异常值并平滑去噪，提高了数据质量。”若不交代四谱共同首点和附件2那262个超100%值的去留及影响，这句话可用于任何数据。另一撞车句是“消除多光束干涉后显著提升精度”，却没有触发依据、同口径前后结果及“显著”的证据。
4. **机械引入与命名式创新。** “众所周知，碳化硅具有广泛应用”“为解决上述问题，首先对数据进行预处理”“创新性融合FFT与最小二乘”。检查这些句子删掉后是否损失任何具体信息；所谓创新若没有指出解决了哪种实际风险、代价是什么、用什么对照证明有效，就仍是模板话术。
5. **结尾不交代失效范围。** “模型鲁棒性强，具有良好的推广价值”后没有折射率假设、使用波段、异常处理和缺少外部标定的限制。摘要可执行的偏离是：先报下游实算的核心结果及适用条件，再给最关键的数据证据和可靠性限制，最后交代问题3分支；现在不得预填任何厚度、检出结论或改善百分比。

## 5. 必然的薄弱环节

1. **假设没有生效位置，参数没有来源。** 开头列“均匀、平行、无吸收、折射率恒定”等假设，后文没有指出各自进入哪个表达式、限定哪个波段，问题3也不说明哪些假设保留、哪些放松。尤其容易把未提供的折射率/消光系数当成题面给定，或不检查厚度与折射率能否被现有观测区分。
2. **预处理、单位与坐标同时失去审计。** 忽略档案而套GBK日期CSV模板；将波数当波长、百分数当比例、10°/15°直接当层内角，或把输出厘米写成微米。即使公式无误，首点替换、超百裁剪、按行号而非波数计算峰距、偷偷插值仍会让正文与实际计算不一致。
3. **灵敏度只声称，区间只贴标签。** 文中写“扰动参数结果变化不大”，却没有扰动值和结果变化量；区间不说明来自哪种模型、重采样单位、相关性假设和失败处理。把每谱7469个相邻波数点当7469次独立厚度测量，或把两个角度当同条件重复实验，会制造无依据的精度感。
4. **多光束必要条件、观测证据与精度影响混为一谈。** 以“有两个界面”“反射率较大”“频谱有谐波”直接作充分判据，不处理相干叠加、有效高阶光束贡献等条件的可核验性，也不排查基线、色散、异常段或处理方式的替代解释。即便谱形支持高阶贡献，也不能跳过“它对本次厚度估计有多大影响”的检验。
5. **多问不呼应，代码与交付物不闭环。** 误把“硅检出多光束干涉”当作交付硅厚度的前提；或问题3完全不回看附件1、2，或不论触发与否都编一个“修正后结果”。检查两角度是否实际都参与计算、问题2基准是否保留、修正前后是否同口径；正文数值是否逐项对应结果JSON/CSV，所有尝试是否有真实实验记录。

## 6. 我们必须偏离的清单

以下按预期评分收益/实施成本排序。每条给出数据锚点、责任动作和验收证据；建议的表图名称是下游待产出项，不是已完成的求解结果。

1. **把“四个文件”当“四个独立样本”、套CSV读取 → 先锁死对象、键和单位。**
   **数据锚点：** 档案`总览`确认4个XLSX、每谱7469行、共29876行、2块晶圆，每块均有10°和15°；四谱有7469个共同波数，范围399.6747—4000.122 cm⁻¹，`数据/data.csv`不存在。`跨文件关系/两两全量核验`确认同片按原始波数一对一关联，无需插值。
   **执行与验收：** 规划师按“附件1、2＝碳化硅；附件3、4＝硅”建任务与结果索引；求解方在读取阶段断言行数、唯一键和同片对齐，保留源附件、原始行号、材料、角度与质量标记，显式记录反射率÷100、角度换算及最终厚度单位。分开估计可以，共同估计也可以，但每个附件须留下参与记录；不能借对齐之名平均掉角度。
   **评分收益：** 以最低成本守住题面C2、C7—C12及四附件覆盖要求，避免材料、角度、单位错误使后续结果整体失效。

2. **“去掉异常值即可” → 将真实异常变成可复核的处理对照。**
   **数据锚点：** 档案`文件档案/工作表/反射率检查`记录四谱在399.6747 cm⁻¹均为0；全部262个超100%点仅在附件2，位于801.278—927.1104 cm⁻¹、原始行835—1096，最大102.7393552%。原因尚未证实。
   **执行与验收：** 求解方先保留原始值并加标记，不将零改缺失、不把超百值截到100、不声称完成校准。对预先确定且覆盖相关区段的分析口径，分别比较首点保留/排除、可疑区段保留/排除及二者组合；同片角度比较需要排段时用一致波数掩码并记录覆盖变化。若最终选段本就不含这些点，明确报告其与选段无交集，不伪造“清洗改善”。结果表列处理口径、点数、厚度变化与分段残差变化；图中标出异常原值。
   **评分收益：** 用现成质量风险支撑问题2的可靠性分析，并防止问题3将测量参考异常误判为高阶干涉；提高可复核性而非宣称某种清洗必然更优。

3. **第三问一律升级复杂模型，或跳过未检出材料 → 先设完整的条件验收表。**
   **数据锚点：** 档案`文件档案`中附件3、4分别是同一硅晶圆的10°、15°观测，各7469行；附件1、2属于另一块碳化硅晶圆。没有任何档案字段已经给出多光束检出结论。
   **执行与验收：** 规划师按题面需求3-1—3-13排“理论必要条件→可观测证据/缺失信息→附件3、4逐附件判断→硅模型、算法、结果”的无条件链；另列附件1、2“是否出现”“是否影响厚度精度”两道判断。求解方的模型对照须使用相同数据口径，报告谱形残差和厚度变化，不能只比训练拟合优度；证据不足须明示，不能冒充证明不存在。仅当碳化硅两条件均成立才执行处理和重算，否则说明不触发依据；触发时与问题2基准逐项对应。
   **评分收益：** 避免第三问漏答与错误触发，同时把“能拟合”提升为“有判断链、有边界”；无需先承诺任何特定复杂模型。

4. **用原谱高相关证明可靠 → 把同片双角变成真正的一致性检查。**
   **数据锚点：** 档案`跨文件关系/两两全量核验`给出附件1、2原谱相关系数约0.998670、反射率均方根差约2.142625个百分点；附件3、4分别约0.994279和3.929849个百分点。这些是光谱描述量，不是厚度误差。
   **执行与验收：** 求解方保留分角度诊断和同片汇总，比较相同波段、相同质量口径下的厚度及残差；若采用共同厚度约束，应说明哪些参数共享、哪些随角度变化。安排一角度确定共享参数、另一角度检验，再交换方向；留出角度不得重新自由调厚度，并明列仍允许调整的幅值/基线项及其限制，防止检验退化成重新拟合。绘图师画双角残差/差值与厚度区间对照，不再用相关热力图充当模型检验。
   **评分收益：** 同时证明两个附件确已使用，给问题2、问题3增加有约束的内部检验；不将不同角度误称独立重复实验，也不冒称获得外部准确度验证。

5. **凭印象填常折射率 → 先交代参数出处与厚度可辨识范围。**
   **数据锚点：** 档案`总览`中的波数跨度为399.6747—4000.122 cm⁻¹，对应波长约2.499924—25.020348 μm；`未随附件提供的建模输入`明确缺少折射率/消光系数随波长的参数以及掺杂浓度。题面C6也没有给出恒定折射率数值。
   **执行与验收：** 求解方建立“参数—出处—固定/估计/情景假设—生效波段—进入位置”表；无已有可核实资料时不得补造文献或把常数写成已知量。常数近似如被采用，须限定波段并做对应参数变化下的厚度稳定性对照；同时检查不同折射率设定能否产生近似等好的拟合却对应不同厚度，不因只有两角度就宣称全部参数唯一可辨。撰稿师将仍依赖假设的绝对厚度明确写成条件性结果。
   **评分收益：** 回应题面关于折射率变化的明确提示，防止“算法精确但输入无来源”；把复杂度用于真正影响厚度解释的环节，而非堆叠算法名称。

6. **全谱同一平滑参数、直接FFT → 小成本验证选段与网格近似。**
   **数据锚点：** 档案`波数网格`的步长保留四位小数后有0.481、0.482、0.4821、0.4822、0.483 cm⁻¹五种，均值约0.4821166711 cm⁻¹，相对端点均匀网格最大偏差约0.0006641805 cm⁻¹。附件1在500—1000与3000—3500 cm⁻¹两段均有1037点，但反射率样本标准差分别约28.852866、0.188733个百分点；这是含趋势和条纹的描述统计，不能直接当噪声标准差。
   **执行与验收：** 求解方优先保留原始波数坐标。若用FFT作候选初始化，只需对比声明的近似等距处理与原坐标核验/明确重采样的结果差异，不因这点轻微不等距就强上复杂算法。选段、基线和平滑参数须记录实际依据，平滑窗口同时给点数和波数跨度；输出波段、有效条纹/候选峰、被拒绝理由和参数变化对照。档案分段仅用于诊断，不得自动命名为吸收带或直接定为拟合边界。
   **评分收益：** 补全问题2算法的可复现细节，区分处理选择造成的变化与物理效应，并在低成本核验后决定是否需要更复杂的方法。

7. **随手给“95%置信区间”、灵敏度无数值 → 区分条件不确定性与情景变化范围。**
   **数据锚点：** 每谱7469点是沿波数排列的观测，两角度只有10°和15°；档案`未随附件提供的建模输入`明确没有真实厚度、同条件重复测量、仪器标称分辨率、入射角误差及反射率误差。波数步长不是仪器分辨率的替代值。
   **执行与验收：** 求解方先输出端点/区段处理、选段、平滑/基线、折射率假设各自的设定值、厚度变化量和适用范围，并区分一次一因素与组合情景。若给统计区间，必须说明随机性来源与相关结构；采用残差块重采样时记录块长选择、重复次数、随机种子、失败次数和每次重估哪些参数，报告条件覆盖口径。若这些假设缺乏依据，只给命名清楚的敏感性范围，不称其为95%置信区间或真实测量误差。
   **评分收益：** 直接支撑问题2需求2-4，避免点数很多就区间很窄的伪精确；同时为问题3“是否影响厚度精度”提供可解释的比较尺度。

8. **漂亮图、流水账摘要各自独立 → 让图、摘要、正文共用证据索引。**
   **数据锚点：** 本题是4条各7469点的光谱对应2块晶圆，并非4个独立对象；可视化必须容纳附件2那262个超过100%的原值，同时显示10°/15°的数据覆盖。这些真实结构足以决定图的分组，无需装饰性创新。
   **执行与验收：** 绘图师按材料分面、按角度区分，先显示完整原谱和异常/选段标记，再显示使用波段的局部拟合与同波数轴残差，最后给同片厚度及有构造说明的区间/敏感性范围；仅触发修正时增加同口径前后对照。先由求解方将关键统计量与结果写入各问`结果/*.json`，再出图；撰稿师使用“语义化标题（问题N）”，摘要按核心结果、实测证据、可靠性边界和分支结论组织。建立“需求号—源附件—结果字段—图表—正文位置”索引，不硬编码另一套数字；实际尝试追加实验记录，未做的比较不写成已验证。
   **评分收益：** 评委能一眼定位每问及每附件的回答，读图能核对结论依据；改善可评分性和复现性，而不是单纯换图型、换标题。
