# 问题2升格1：共同峰序—整数级次匹配

## 1. 改动结论

本升格把问题2的主方法从“连续反射率上的双角色散变投影”改为“离散信号处理 + 整数级次一致性”。旧主线把共享厚度、参考折射率、色散和角度响应放进连续强度模型，并用线性系数投影消去基线与幅值；既有真实附件结果给出10.80351642616071微米的条件点估计，但五折厚度相对极差为0.7604164048265782，测试反射率经验覆盖率为0.490625，因此两次G2解读仍未通过。

升格1保留真实附件、碳化硅同片双角、1200--3800 cm^-1共同窗口、480个共同原坐标点、两折连续留段及区间覆盖协议；只替换“由强度残差直接选择厚度”的主识别机制。新主方法先在训练连通段提取峰/谷事件，再用同型事件之间应相差整数级次的离散约束筛厚度；强度只在选定级次候选后用于相位折叠的中位数模板预测。这样把厚度识别从连续振幅补偿转为谱峰位置和整数级次的组合约束，属于另一大类方法。

脚本为 `求解/问题2/升格1/求解.py`，结果写入同级 `结果/`。按任务要求本轮只写未主动运行；结果声明中的数值锚点引用同一真实附件上的既有峰序原型结果，不能冒充本升格脚本已执行结果。

## 2. 数据和物理量

记波数为 σ，单位为 cm^-1；记入射角为 θ，数据档案给出的两个角度为10°、15°，计算时转为弧度；记反射率比例为 Rθ(σ)，原始百分数先除以100。记待估外延层厚度为 d，内部用cm，最终用 d_um=10^4 d 表示微米；记层内参考折射率为 n_ref，经验色散系数为 c。这些变量分别对应题面反射率观测、双角同片几何厚度和数据档案明确缺失的光学输入。

数据档案给出附件1、2各7469点，波数逐行相同，覆盖399.6747--4000.122 cm^-1，两谱是同一碳化硅晶圆的10°和15°观测；原始相关为0.9986697662463415，均方根差为2.1426246551704193个百分点。附件2存在262个超过100%的原始值，最大值102.7393552%；升格脚本保留原值，不以“物理范围”擅自裁剪。主窗口1200--3800 cm^-1避开共同首点399.6747 cm^-1和附件2的801.278--927.1104 cm^-1超界段，但窗口边界改变仍列为灵敏度情景。[数据档案:总览；数据档案:跨文件关系/附件1—附件2；数据档案:质量问题与决策]

## 3. 从干涉相位到离散级次

### 3.1 层内传播因子

外部介质为空气，取其折射率为1；这是界面几何的基准约定，不把它当作待估材料参数。由切向波矢守恒，层内纵向折射因子为

`qθ(σ) = sqrt(n(σ)^2 - sin(θ)^2)`。

根号内的减项来自空气侧入射方向，正根对应向层内传播的分支；该式承接问题一两束表达式的角度几何关系。数据档案没有提供折射率曲线，所以本问不能直接代入材料手册常数。[计划.json/问题2/建模步骤；数据档案:未随附件提供的建模输入]

### 3.2 经验色散参数化

为让波数跨度内的条纹级次可以比较，升格仍保留计划允许的低维经验色散，但它只服务于级次坐标，不解释成已知材料常数：

`n(σ) = n_ref + c × ((2000/σ)^2 - 1)`。

式中2000 cm^-1是参照波数，使 n(2000)=n_ref；c控制相对于该参照的弯曲。该式来自计划中问题2的经验色散形式，而不是由实测折射率直接拟合得到；因此脚本把 n_ref 和 c 的候选范围、固定±3%情景和常色散对照全部写入结果。[计划.json/问题2/建模步骤；数据档案:未随附件提供的建模输入]

### 3.3 相位周期数

一次往返的相位差由光程 2d qθ 与波数 σ 相乘得到，弧度形式为

`Φθ(σ) = 4π d σ qθ(σ)`。

除以2π把弧度转成干涉周期数，并用 d_um=10^4 d 换单位，得到脚本实际使用的级次坐标

`uθ(σ; d_um, n_ref, c) = 2 × (d_um/10^4) × σ × qθ(σ)`。

这一步保留双角共同厚度，但允许10°和15°有不同的未知起始相位；共享的是 d、n_ref、c，不是把两谱强度强行相等。[计划.json/问题2/本题定制改造；假设台账_问题2_升格1:A1]

### 3.4 峰谷事件和整数约束

在每个训练连通段上，用局部移动平均得到慢变基线 bθ,t(σ)，再定义去基线信号

`eθ,t(σi) = Rθ(σi) - bθ,t(σi)`。

下标t表示训练连通段；基线只在训练段内计算，不能跨过测试块保护带。对平滑后的e，若点i同时不小于左右邻点，则记为峰；若同时不大于左右邻点，则记为谷；当前默认以本段差分尺度的2倍作为事件显著度门槛，并在2、3、4倍情景中复核。这个定义把全谱慢变包络与局部条纹事件分开，且不改变原始反射率。

设同一角度、同一类型的相邻事件为i、j。同型峰或同型谷之间的周期差应接近整数：

`Δuθ,ij = uθ(σj) - uθ(σi) ≈ mθ,ij，mθ,ij ∈ Z`。

因此定义级次残差 `ρθ,ij = |Δuθ,ij - round(Δuθ,ij)|`。相邻峰与谷的相位差还应接近半周期。令pθ、vθ分别为峰、谷事件的u的小数部分中位数，再加入 `ρpvθ = |pθ - vθ - 1/2 - round(pθ - vθ - 1/2)|`。

对两个角度和两种事件类型，升格脚本以所有ρ的中位数加上半峰谷残差与漏级惩罚形成离散代价J(d,n_ref,c)。候选只按J和支持的同型级次数排序，不调用强度残差优化d，也不允许逐点自由相位吞掉条纹。这直接落实计划中“峰序匹配不以两折厚度直接平均”和“受限常相位不得扩成逐点自由相位”的定制要求。[计划.json/问题2/备选方法；计划.json/问题2/本题定制改造]

自批评发现，若把同型事件的近零周期差直接按整数0计分，低厚度边界会因“代价小但没有完整条纹周期”而被错误偏好；当前实现对小于半周期的同型差加入高惩罚，并将默认显著度门槛调整为训练段差分尺度的2倍，仍保留2、3、4倍情景。这个修正只改变离散级次的物理可行性约束，不回到旧的连续强度投影。

## 4. 从旧公式到升格公式

旧主线的强度层写成

`Rθ(σ) = bθ(x) + Aθ(x) cos(Φθ(σ) + ψθ)`。

其中bθ为二次基线，Aθ为一次幅值，x为训练数据标准化坐标；给定d、n_ref、c、ψθ后用线性投影求b、A。这个公式能重建连续强度，但未知基线、幅值、常相位和色散可以共同补偿，既有结果的五折厚度极差达到0.7604164048265782。

升格1明确改为

`{(σθ,r, sθ,r)} -> {uθ(σθ,r)} -> min J(d,n_ref,c)`，

其中sθ,r∈{+1,-1}表示峰或谷，J只比较相邻事件的整数级次和峰谷半周期关系。也就是说，旧方法的连续观测值—强度残差链被改成“观测值—事件—级次”的离散链；幅值和基线不再参与厚度选择。

新方法仍需要强度作预测诊断时，先冻结离散候选，再在相位u mod 1的48个箱内取训练残差中位数作为模板：

`Rhatθ(σ) = bhatθ(σ) + Interp[ median{eθ(σi): bin(uθ(σi) mod 1)=k} ]`。

该预测公式是冻结级次后的相位折叠重建，不反过来改变厚度候选；它只用于和主线同口径地报告连续留段标准化RMSE、二次趋势基线及反射率覆盖。上述“旧式强度投影”与“新式离散级次选择”的差异是本次升格的实质，不是把旧方法换名字。

## 5. 算法流程和时间保护

1. 校验附件哈希、Sheet1、7469行、波数严格递增及两角逐行一致；原始反射率百分数除以100，保留源行号。
2. 在1200--3800 cm^-1按原坐标抽取480点，两角共用索引，每40点为一块；不插值、不按反射率异常删点。
3. 对每个连续训练段计算移动基线、去基线事件和显著度；事件检测不访问校准或测试反射率。
4. 在d∈[0.5,40]微米、n_ref∈[1.2,6]、c∈[-1,1]的离散候选中计算J，保留前12个候选并对厚度邻域做21点离散加密；每个循环检查18分钟软截止。
5. 冻结每折候选，使用校准块绝对残差的90% split-conformal顺序统计量构造对称反射率区间，再仅在测试块计算预测误差和覆盖率。
6. 完成两折、五折、峰序近优剖面、显著度/基线/网格/折射率/窗口灵敏度后，写入厚度结果、验证、区间覆盖、参数剖面、留段预测和基准交接；每折结束先写中间JSON。

脚本的所有主循环均有预算检查，异常中止也会写入执行状态和数值回退答案；这满足“验证未通过时降级表述而不留空”的要求。结果中的实际用时秒由time.monotonic记录，未在本轮只写任务中伪造执行耗时。

## 6. 验证、区间与同口径指标

基线沿用计划口径：训练块二次趋势预测作为结构基线；主方法的连续留段标准化RMSE为八个测试块逐块计算

`NRMSEb = sqrt(mean((Ri - Rhat_i)^2)) / (Q0.75(etrain) - Q0.25(etrain))`，

再对八块等权平均。mb是该测试块点数，分母是同角训练去基线残差IQR；该定义来自计划规定的连续留段指标，不能解读为厚度误差。

区间采用卡1要求的校准—留出协议：若校准残差绝对值排序为a(1)≤...≤a(n)，名义90%半宽取 `q0.90 = a(ceil((n+1)×0.90))`，反射率区间为 `[Rhat(σ)-q0.90, Rhat(σ)+q0.90]`。脚本报告名义覆盖率0.90、测试经验覆盖率、覆盖点数和覆盖不足标记；该区间只针对反射率点预测，不能改写成厚度置信区间。[运行时/方法卡片库.md:卡1]

交叉印证包括：两角共享d、n_ref、c的峰序候选、两折连续留段、五折连续留段、厚度—级次代价剖面、峰显著度和折射率±3%情景。双角高相关只说明共同波数上的谱形相似，不能单独证明厚度准确；数据档案已经给出两角均方根差2.1426246551704193个百分点，故保留角度特有模板。没有把问题一合成误差移植到实测厚度，也没有生成合成头条数字。

## 7. 结果解释边界
